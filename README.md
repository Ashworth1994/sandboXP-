# sandboXP-

A lightweight sandbox-style landing page and prototype workspace for rapid experimentation.

## Overview

This project creates a polished single-page interface for `sandboXP-`, designed as a playful prototype lab where teams can:

- build and test ideas quickly
- experiment in isolated sandbox sessions
- iterate on product concepts without friction

## Run locally

Open `index.html` directly in a browser, or serve it with a small local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `script.js` — interactive session generation and live status updates

## Notes

The design uses a dark, futuristic dashboard aesthetic with responsive behavior for desktop and mobile layouts.
